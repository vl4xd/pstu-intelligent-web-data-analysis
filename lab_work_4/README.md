## 1. Описание проекта

Программа на Python для сбора, предварительной обработки и первичного анализа веб-данных.

В проекте используются:
- **Scrapy** — фреймворк для сбора веб-данных.
- **Playwright** — инструмент взаимодействия с динамическими веб-страницами (SPA).
- **ftfy** — библиотека исправления ошибок кодировки текста.
- **pytest** — инструмент автоматического тестирования.

Реализованы два паука:
- **NewsSpider** — сбор новостных публикаций с Habr.
- **EcommerceSpider** — сбор товаров из демонстрационного интернет-магазина SauceDemo.

Собранные данные проходят предварительную обработку, проверку на дубликаты и валидацию. Результаты сохраняются в форматах JSON и CSV.

## 3. Принцип работы

### 3.1. Сбор данных

**NewsSpider**
- Использует новостной сайт Habr.
- Извлекает заголовки, URL, автора, дату публикации и краткое содержание.
- Поддерживает фильтрацию по ключевым словам.
- Использует пагинацию для сбора публикаций.

**EcommerceSpider**
- Использует демонстрационный интернет-магазин SauceDemo.
- Авторизуется с помощью тестовой учётной записи.
- Использует Playwright для работы с динамически загружаемым каталогом.
- Извлекает названия товаров, цены, валюту, доступность и изображения.

### 3.2. Предварительная обработка

Реализованы три конвейера обработки данных:

- **CleaningPipeline** — исправляет ошибки кодировки с помощью ftfy, удаляет лишние пробелы и приводит текст к нижнему регистру.
- **DuplicationPipeline** — исключает повторяющиеся записи по URL.
- **ValidationPipeline** — проверяет наличие обязательных полей: названия и URL.

### 3.3. Настройки и обработка ошибок

В проекте настроены:
- повторные попытки HTTP-запросов;
- обработка HTTP-статусов 429, 500, 502, 503 и 504;
- задержка между запросами;
- ограничение параллельных запросов;
- логирование работы пауков и компонентов проекта.

## 4. Установка и настройка

Для работы проекта необходим Python версии 3.12 или выше.

1. Клонировать репозиторий и перейти в его каталог:

```bash
git clone -b lab-work-4 https://github.com/vl4xd/pstu-intelligent-web-data-analysis.git
cd pstu-intelligent-web-data-analysis/lab_work_4
```

2. Создать виртуальное окружение:

```bash
python -m venv .venv
```

3. Активировать виртуальное окружение в Git Bash:

```bash
source .venv/Scripts/activate
```

4. Установить зависимости:

```bash
pip install -r requirements.txt
```

5. Установить браузер Chromium для Playwright:

```bash
playwright install chromium
```

## 5. Запуск программы

Для запуска используется CLI-скрипт `run_spider.py`.

### Сбор новостных публикаций

```bash
python run_spider.py --spider news
```

### Сбор товаров интернет-магазина

```bash
python run_spider.py --spider ecommerce
```

### Фильтрация новостей по ключевым словам

```bash
python run_spider.py --spider news --keywords "python,программирование"
```

### Сохранение результатов в JSON

```bash
python run_spider.py --spider news --output data/raw/news.json
```

### Сохранение результатов в CSV

```bash
python run_spider.py --spider ecommerce --output data/exports/products.csv
```

Формат экспорта определяется расширением выходного файла.

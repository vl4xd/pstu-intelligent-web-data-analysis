## 1. Описание проекта

Программа на Python для тематического моделирования коллекций веб-документов методами **LDA** и **NMF** с оценкой качества тем через **Coherence Score (c_v)**.

В проекте используются:
- **scikit-learn** — векторизация (`CountVectorizer`, `TfidfVectorizer`) и модели `LatentDirichletAllocation`, `NMF`.
- **gensim** — расчёт Coherence Score (`c_v`).
- **pymorphy3** — лемматизация русскоязычных текстов.
- **NLTK** — базовый список стоп-слов.
- **BeautifulSoup4** — очистка HTML-мусора из описаний товаров.
- **matplotlib / seaborn** — визуализация тем и матрицы «документ — топик».

Реализован CLI-пайплайн, который:
- загружает и предобрабатывает корпус текстов;
- обучает LDA и/или NMF;
- подбирает оптимальное число топиков K по Coherence;
- сравнивает методы между собой;
- сохраняет ключевые слова, графики и метрики.

## 4. Принцип работы

### 4.1. Предобработка (`preprocess.py`)

Пайплайн очистки текста:

1. **Удаление HTML-артефактов** через `BeautifulSoup`: теги (`<div>`, `<strong>` и др.), entities (`&nbsp;`, `&amp;`), URL.
2. **Нормализация**: приведение к нижнему регистру, удаление пунктуации и цифр.
3. **Токенизация и лемматизация** через `pymorphy3`.
4. **Фильтрация стоп-слов**: базовый список NLTK + кастомный список (слова-паразиты и IT-общие термины: `который`, `это`, `система`, `данные`, `код`).

### 4.2. Векторизация и модели (`model.py`)

Строгое соответствие требованиям методички:

- **LDA** обучается на **`CountVectorizer`** (счётчики).
- **NMF** обучается на **`TfidfVectorizer`** (TF-IDF).

Оба векторайзера настроены с `max_df=0.5, min_df=2` — это отсекает слова, встречающиеся более чем в 50% документов, и слова-гапаксы.

### 4.3. Оценка качества

- **Coherence Score (c_v)** из `gensim.models.coherencemodel`.
- **Автоподбор K** (`--topics auto`): перебор K от 3 до 20 с сохранением всех score и выбором максимума.

### 4.4. Визуализация (`visualize.py`)

- `plot_top_words` — бар-чарты топ-слов по каждому топику (слайд 20 методички).
- `plot_coherence` — зависимость Coherence от K с отмеченным оптимумом (слайд 16).
- `plot_doc_topic_heatmap` — матрица «документ — топик» (слайд 12).

## 6. Запуск программы

Все команды выполняются из каталога `lab_work_5`.

### Тематическое моделирование новостей через LDA с автоподбором K

```bash
python main.py --dataset news --method lda --topics auto --output news_lda_auto
```

### Сравнение LDA и NMF на товарах при фиксированном K=10

```bash
python main.py --dataset products --method both --topics 10 --compare --output products_both
```

### Сравнение LDA и NMF на новостях при фиксированном K=10

```bash
python main.py --dataset news --method both --topics 10 --compare --output news_both
```

### Ограничение объёма документов

```bash
python main.py --dataset news --method lda --topics auto --limit 300 --output news_lda_auto_300
```

### Доступные флаги CLI

| Флаг | Описание |
|---|---|
| `--dataset` | `news` \| `products` |
| `--method` | `lda` \| `nmf` \| `both` |
| `--topics` | число K или `auto` (перебор по Coherence в диапазоне `--min-k`..`--max-k`) |
| `--min-k` | нижняя граница K при `--topics auto` (по умолчанию 3) |
| `--max-k` | верхняя граница K при `--topics auto` (по умолчанию 20) |
| `--compare` | сравнить LDA и NMF на одном датасете, сохранить `comparison.json` |
| `--output` | префикс выходных файлов (JSON / PNG) |

## 8. Вывод

В рамках лабораторной работы реализован полный пайплайн тематического моделирования веб-данных: от предобработки текста до интерпретации и визуализации тем.

Сравнение LDA и NMF на двух предметных областях показало, что **NMF устойчиво превосходит LDA** по Coherence как на коротких текстах (описания товаров, c_v = 0.626 против 0.548), так и на средних (новости Habr, c_v = 0.461 против 0.302). Основная причина — использование TF-IDF в NMF, что подавляет частотные общие слова и усиливает специфичные термины.

Реализованы CLI с флагами `--method`, `--topics auto`, `--compare`, `--output`, автоподбор K по Coherence, визуализация тем и матрицы «документ — топик», а также экспорт ключевых слов в JSON.

# Лабораторная работа №3: Wikimedia API

**Автор:** Платонов Владислав, АСУ8-25-1м

Программа на Python для сбора информации из Wikimedia. По заданной предметной области приложение находит статьи русскоязычной Википедии, получает текст и внутренние ссылки, собирает связанные изображения из Wikimedia Commons, сохраняет результаты в JSON и строит граф связей между статьями. Дополнительно предусмотрена отдельная CLI-команда для получения Picture of the Day (POTD) из Wikimedia Commons.

## Принцип работы

Основной сбор данных выполняется в несколько этапов:

1. **Ввод предметной области.** Пользователь передаёт поисковый запрос через командную строку.
2. **Поиск начальной статьи.** `WikipediaCollector` обращается к MediaWiki API и находит статью, соответствующую запросу.
3. **Сбор статей.** С помощью обхода в ширину (BFS) программа последовательно получает статьи и ссылки на другие статьи Википедии. Количество собираемых статей ограничивается параметром `--limit`.
4. **Сохранение текстовых данных.** Для каждой статьи сохраняются название, язык, URL, текст и список ссылок. Результат записывается в `output/articles.json`.
5. **Сбор изображений.** `CommonsCollector` ищет изображения в Wikimedia Commons по названиям собранных статей. Результаты поиска сохраняются в `output/images.json`.
6. **Построение графа.** Статьи становятся вершинами ориентированного графа. Ребро создаётся, если одна собранная статья содержит ссылку на другую собранную статью.
7. **Экспорт графа.** Граф сохраняется в интерактивном HTML-файле PyVis (`output/graph.html`) и в текстовом формате DOT (`output/graph.dot`).

Дополнительная команда `potd.py` отдельно получает информацию о Picture of the Day, скачивает изображение и сохраняет его описание в текстовый файл.

Таким образом, основная схема обработки выглядит следующим образом:

```text
Запрос о предметной области
        |
        v
Поиск начальной статьи через Wikipedia API
        |
        v
Обход связанных статей (BFS)
        |
        +------> articles.json
        |
        v
Поиск изображений в Wikimedia Commons
        |
        +------> images.json
        |
        v
Построение графа ссылок
        |
        +------> graph.html (PyVis)
        |
        +------> graph.dot (DOT)
```

## Возможности

- сбор статей Википедии по пользовательскому запросу;
- выбор языковой версии Википедии;
- обход связанных статей с использованием алгоритма BFS;
- ограничение количества собираемых статей;
- получение текста статей и внутренних ссылок;
- обработка сетевых ошибок, ошибок API и ограничений частоты запросов;
- повторные попытки при временных сетевых ошибках и ограничениях Wikimedia;
- поиск изображений в Wikimedia Commons по названиям собранных статей;
- сохранение статей и изображений в JSON;
- построение ориентированного интерактивного графа с помощью PyVis;
- экспорт графа в формат DOT;
- отдельная CLI-команда для получения Picture of the Day и сохранения изображения с описанием.

### Назначение основных файлов

#### `main.py`

Основная точка входа. Принимает поисковый запрос и параметры запуска, запускает сбор статей Википедии, сохраняет JSON, собирает изображения Wikimedia Commons и строит HTML- и DOT-графы.

#### `potd.py`

Отдельная CLI-точка входа для получения Picture of the Day. Не запускает основной сбор статей. Позволяет указать каталог для сохранения результата.

#### `collectors/wikipedia.py`

Содержит класс `WikipediaCollector`. Выполняет поиск начальной статьи и сбор связанных статей через MediaWiki API. Использует обход в ширину (BFS), ограничение количества статей, задержку между запросами и повторные попытки при временных ошибках.

#### `collectors/commons.py`

Содержит класс `CommonsCollector`. Ищет изображения в Wikimedia Commons по названиям статей, получает URL, описание, сведения об авторе и лицензии, а затем сохраняет результаты в JSON.

#### `collectors/potd.py`

Содержит класс `PictureOfTheDayCollector`. Получает данные о Picture of the Day через API Wikimedia Commons, скачивает изображение и сохраняет описание, автора, лицензию и ссылки в TXT-файл.

#### `collectors/exceptions.py`

Содержит специализированные исключения для обработки ошибок при работе с Wikimedia API, сетевых проблем, ограничений запросов и некорректных ответов.

#### `models/article.py`

Определяет dataclass `Article`, представляющий собранную статью: название, язык, URL, текст и список ссылок.

#### `storage.py`

Содержит функции сохранения и загрузки статей в JSON. В файл записываются метаданные экспорта и список статей.

#### `graph.py`

Содержит класс `ArticleGraph` и функцию `build_graph()`. Добавляет статьи в качестве узлов, а ссылки между собранными статьями — в качестве ориентированных рёбер. Сохраняет граф в HTML и DOT.

#### `lib/`

Локальные JavaScript-ресурсы PyVis/vis.js. Они используются HTML-графом для отображения и взаимодействия с узлами и рёбрами.

#### `output/`

Каталог результатов работы программы: JSON-файлы, графы и материалы Picture of the Day.

## Требования

- Python **3.9 или новее**;
- библиотеки, перечисленные в `requirements.txt`;
- подключение к интернету для обращения к Wikimedia API.

В проекте используются:

- `requests` — HTTP-запросы к Wikimedia API;
- `pyvis` — построение интерактивного графа.

## Использование

Все команды выполняются из корневой директории проекта.

### Основной сбор данных

Базовый запуск для предметной области «Искусственный интеллект»:

```bash
python main.py "Искусственный интеллект"
```

По умолчанию программа использует русскоязычную Википедию, собирает до 30 статей и ищет до трёх изображений для каждой статьи.

Пример с увеличенным количеством изображений:

```bash
python main.py "Искусственный интеллект" --limit 30 --images-limit 5
```

Выбор языковой версии Википедии:

```bash
python main.py "Artificial intelligence" --language en --limit 30
```

Поддерживаемые значения `--language`: `ru`, `en`, `de`, `fr`.

Изменение пути сохранения JSON со статьями:

```bash
python main.py "Искусственный интеллект" --output output/my_articles.json
```

Открытие графа в браузере после построения:

```bash
python main.py "Искусственный интеллект" --show True
```

### Получение Picture of the Day

POTD запускается отдельно от основного сбора:

```bash
python potd.py
```

По умолчанию изображение и описание сохраняются в `output/potd/`.

Можно указать другой каталог:

```bash
python potd.py --output output/my_potd
```

В каталоге создаются два файла с одинаковым базовым именем:

- `picture_of_the_day.<расширение>` — изображение;
- `picture_of_the_day.txt` — описание и сведения об изображении.

## Формат результатов

### `articles.json`

JSON содержит объект с метаданными экспорта и массивом `articles`. Для каждой статьи сохраняются:

- `title` — название статьи;
- `language` — языковая версия Википедии;
- `url` — адрес статьи;
- `text` — текст статьи;
- `links` — список названий связанных статей.

### `images.json`

JSON содержит список найденных изображений. Для каждого результата могут сохраняться:

- `title` — название файла Wikimedia Commons;
- `image_url` — URL изображения или миниатюры;
- `original_url` — URL оригинального файла;
- `file_page` — страница файла на Wikimedia Commons;
- `description` — описание изображения;
- `author` — автор;
- `license` — краткое обозначение лицензии;
- `article_title` — название статьи, для которой искалось изображение;
- `article_url` — URL этой статьи.

### `graph.html`

Интерактивный ориентированный граф PyVis. Вершины соответствуют собранным статьям, рёбра — ссылкам между ними. При наведении на узел отображаются название статьи, язык и ссылка на неё.

### `graph.dot`

Текстовое представление того же ориентированного графа в формате DOT. Вершины и связи можно просматривать в текстовом редакторе или использовать в совместимых с DOT инструментах.

### `picture_of_the_day`

Изображение POTD и одноимённый TXT-файл с датой, названием, описанием, автором, лицензией и ссылками на файл.

## Особенности и ограничения

1. **Доступность Wikimedia.** Внешние API и файловые серверы могут временно быть недоступны или ограничивать запросы. В таком случае программа выводит сообщение об ошибке; успешное получение всех материалов не может быть гарантировано.
2. **Ограничения частоты запросов.** Сборщик Википедии использует задержку между запросами и повторные попытки при временных ошибках и ограничениях API.
3. **Количество статей.** `--limit` задаёт верхнюю границу сбора. Фактическое количество может быть меньше, если связанные страницы недоступны, не найдены или обход закончился раньше.
4. **Связи графа.** В граф попадают только связи между статьями, которые вошли в текущую выборку. Ссылки на несобранные страницы отдельными узлами не становятся.
5. **Поиск изображений.** Изображения ищутся по названию статьи. Результаты поиска могут быть тематически неидеальными; наличие изображения для каждой статьи не гарантируется.
6. **Picture of the Day.** Получение POTD выполняется отдельной командой. Доступ к API и загрузка файла зависят от доступности сервисов Wikimedia и применяемых ими правил автоматизированного доступа. При отказе сервера программа сообщает об ошибке.
7. **User-Agent и контактные данные.** Для автоматизированных запросов необходимо указывать корректный контактный адрес в User-Agent. В `collectors/wikipedia.py` контакт читается из переменной окружения `WIKIMEDIA_CONTACT` (если она не задана, используется значение по умолчанию в коде). В `collectors/commons.py` и `collectors/potd.py` контакт указан непосредственно в исходном коде — перед использованием замените пример адреса на свой.
8. **Локальные ресурсы графа.** Каталог `lib/` нужен для работы HTML-графа при использовании локальных JavaScript-ресурсов PyVis. Не удаляйте его, если хотите сохранить автономное отображение графа.

## Устранение типичных проблем

### `ModuleNotFoundError`

Проверьте, что активировано виртуальное окружение, и установите зависимости:

```bash
python -m pip install -r requirements.txt
```

### Не удалось собрать статьи

Проверьте подключение к интернету, поисковый запрос и доступность `https://ru.wikipedia.org`. При необходимости попробуйте другой запрос или языковую версию.

### Ошибка HTTP 429 или сообщение об ограничении запросов

Wikimedia ограничила частоту запросов. Дождитесь снятия ограничения и повторите запуск позже. Не увеличивайте частоту запросов.

### Ошибка 403 при получении POTD или скачивании изображения

Проверьте корректность контактного адреса в User-Agent. Если сервер сообщает о нарушении robot policy, не пытайтесь обходить ограничение альтернативными адресами или повторными запросами: проверьте действующие правила Wikimedia и повторите попытку позднее, если доступ разрешён.

### HTML-граф не отображается

Убедитесь, что рядом с проектом сохранён каталог `lib/`, а файл `output/graph.html` создан. Если граф переносится отдельно от проекта, локальные ресурсы, на которые он ссылается, также должны быть доступны.

### Не удалось получить Picture of the Day

Проверьте подключение к интернету и повторите запуск позднее:

```bash
python potd.py
```

## Примечание

Программа использует открытые интерфейсы Wikimedia для учебной работы. При её запуске следует соблюдать правила использования API и файловых сервисов Wikimedia, указывать корректный User-Agent и не создавать чрезмерную нагрузку на серверы.

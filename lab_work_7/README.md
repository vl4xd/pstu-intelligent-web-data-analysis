## 1. Описание проекта

Проект представляет собой рекомендательную систему для медиакаталога на основе датасета **MovieLens Latest Small**.

Цель работы — разработать и сравнить несколько подходов к построению персональных рекомендаций фильмов, оценить качество рекомендаций и исследовать разнообразие рекомендательной выдачи.

Реализованы следующие алгоритмы:

- **Popularity** — базовая модель популярности фильмов.
- **Content-based TF-IDF** — контентная фильтрация на основе названий и жанров фильмов.
- **Collaborative SVD** — коллаборативная фильтрация с использованием матричной факторизации SVD.
- **Implicit ALS** — коллаборативная фильтрация с использованием ALS для неявной обратной связи.

Для оценки качества используются Precision@K, Recall@K, MAP@K и NDCG@K. Дополнительно рассчитываются покрытие каталога и разнообразие рекомендаций (Intra-List Diversity, ILD).

## 3. Источник данных

Используется датасет **MovieLens Latest Small**.

Источник: [Hugging Face — ashraq/ml-latest-small](https://huggingface.co/datasets/ashraq/ml-latest-small).

Характеристики набора данных:

- 100 836 пользовательских оценок;
- 9 724 фильма;
- 610 пользователей;
- шкала оценок от 0.5 до 5.0.

Данные содержат информацию о фильмах и пользовательских оценках. В исходном наборе отсутствуют временные метки взаимодействий.

## 4. Принцип работы

Эксперимент состоит из следующих этапов:

1. Загрузка и исследовательский анализ данных (EDA).
2. Подготовка обучающей и тестовой выборок.
3. Построение базовой модели популярности.
4. Реализация контентной и коллаборативных моделей.
5. Генерация персональных рекомендаций.
6. Оценка качества моделей.
7. Сравнение моделей по метрикам качества.
8. Анализ разнообразия и покрытия каталога.

Разделение данных выполняется отдельно для каждого пользователя в пропорции 80/20.

Оценки от 4.0 и выше считаются положительными взаимодействиями при расчёте метрик релевантности.

## 6. Запуск программы

Для просмотра доступных команд:

```bash
py main.py --help
```

### Основные команды

| Команда | Назначение |
|---|---|
| `py main.py eda` | Исследовательский анализ данных |
| `py main.py split` | Разделение данных на train/test |
| `py main.py recommend` | Генерация рекомендаций |
| `py main.py evaluate` | Оценка качества моделей |
| `py main.py compare` | Сравнение моделей |
| `py main.py diversity` | Анализ разнообразия рекомендаций |
| `py main.py all` | Запуск полного экспериментального конвейера |

### Генерация рекомендаций

По умолчанию используется ALS, пользователь с ID 414 и значение K из конфигурации.

```bash
py main.py recommend
```

Выбор конкретной модели:

```bash
py main.py recommend --model popularity --user-id 414
py main.py recommend --model content_based --user-id 414
py main.py recommend --model svd --user-id 414
py main.py recommend --model als --user-id 414
```

Запуск всех моделей:

```bash
py main.py recommend --model all --user-id 414
```

Изменение количества рекомендаций:

```bash
py main.py recommend --model als --user-id 414 -k 20
```

### Оценка качества

Оценка всех моделей:

```bash
py main.py evaluate --model all
```

Оценка отдельной модели:

```bash
py main.py evaluate --model als
```

### Сравнение моделей и анализ разнообразия

```bash
py main.py compare
py main.py diversity
```

### Полный эксперимент

```bash
py main.py all
```

Команда последовательно запускает EDA, разделение данных, оценку четырёх моделей, итоговое сравнение и анализ разнообразия.

# Практика 1: Конскольное приложение "Common Crawl"

**Цель:** собрать CLI-приложение для поиска по архиву Common Crawl и вывода результатов

**Аргументы командной строки:**

|Аргумент     |Тип        |Описание   	                                    |
|---	      |---	      |---	                                            |
|`keywords`   |позиционные|Одно или несколько ключевых слов для поиска      |
|`--domain`   |опция      |Фильтр по домену (например: pstu.ru)             |
|`--limit`    |опция      |Ограничение числа результатов (по умолчанию: 10) |
|`--show-text`|флаг       |Загрузить и показать фрагмент текста страницы    |

**Вывод результатов:**

|URL|Дата архивации|Заголовок страницы|Фрагмент текста (опц.)|
|---|---	       |---               |---                   |
